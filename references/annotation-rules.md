# 注音写法规范（annotation-rules）

错音修复的唯一写法权威。格式与主仓 `scripts/annotate-polyphones.py` 完全一致，
修复时**字典优先、直改兜底**（见 §4）。

## 1. 基本格式

IndexTTS-2.5 用**标签**把读音显式绑定到指定汉字：

- 格式 **`<目标字|读音>`**，读音为**大写拼音 + 声调数字 1-5**
  （如 `<不|FOU3>`、`<般|BO1>`、`<行|XING2>`）
- 声调约定：`1` 阴平 `2` 阳平 `3` 上声 `4` 去声 `5` 轻声
- **只包裹出问题的字**，相邻汉字保持原样；标签内**保留汉字本身**，
  仅覆盖其读音（strip 后可还原为原文）：

| 原文 | 注音后 | 说明 |
|---|---|---|
| 生实信不 | 生实信`<不\|FOU3>` | 只包裹「不」 |
| 阿耨 | 阿`<耨\|NUO4>` | 只包裹「耨」 |
| 我相 | 我`<相\|XIANG4>` | 只包裹「相」 |
| 般若 | `<般\|BO1><若\|RE3>` | 整词两字都改 → 逐字标签 |
| 南无阿弥陀 | `<南\|NA2><无\|MO2><阿\|A1><弥\|MI2><陀\|TUO2>` | 整段音译 → 逐字标签 |

> 旧版写法（混排拼音直接替换多音字，如 `我XIANG4`）**已废弃**；
> 历史文件仍可被解析/兼容，但新注音一律用标签。

## 2. 两层规则（annotate-polyphones.py）

### WORD_RULES — 整词匹配（首选，带语境锚，安全）

```python
WORD_RULES = [
    ("生实信不", "生实信<不|FOU3>"),   # (原文词, 替换串)
    ("般若", "<般|BO1><若|RE3>"),
    ("我相", "我<相|XIANG4>"),
]
```

- 左串 = 原文里出现的**完整词**（含上下文字）
- 右串 = 带 `<字|读音>` 标签的替换串：**未注音的字保持汉字**，
  需注音的字写成 `<原字|读音>`
- **优先加词条**：语境即锚点，不会误伤同字的其他读音

### CHAR_RULES — 字符级匹配（次选，必须给排除词）

```python
CHAR_RULES = [
    ("重", "ZHONG4", ["重新", "重复", "重来", "重庆"]),   # (字, 读音, 排除语境)
]
```

- 命中时生成 `<字|读音>`（上例 → `<重|ZHONG4>`）
- 只有当错误**到处都发生**、无法用词锚定时才用
- 排除词同时检查字的**前文与后文**；给不全排除词会误注

### 应用顺序

1. 先 WORD_RULES（逐条 find，跳过已注音标签区域）
2. 再 CHAR_RULES（跳过标签内字符）
3. 已注音区域（`<字|读音>` 标签内）不会被二次替换

## 3. 对比报告 → 注音的转换

`report.md` §3 错音明细给出：

| 列 | 用途 |
|---|---|
| `字` + `模型理解`（带调，如 `fou3`） | 要改的目标读音 → 直接转大写 `FOU3`（缺声调数字补 `5`，轻声） |
| `上下文` | 构造 WORD_RULES 的左串：取覆盖该字的词（3-6 字），例：`上下文=生实信不` |
| `建议注音` | 报告里的 `[A-Z]+[1-5]` 建议值；落地时包成 `<该字|建议值>` |

**例（0008 实战）**：
报告 `字=不 模型理解=fou3 建议注音=FOU3 上下文=…生实信不…`
→ WORD_RULES 加 `("生实信不", "生实信<不|FOU3>")`
→ 重跑注音脚本 → 重生成第 2、8、39 行。

## 4. 修复路径

### 首选：字典规则（系统性，惠及其他项目）

```bash
# 1. 编辑主仓 scripts/annotate-polyphones.py，向 WORD_RULES 追加元组
# 2. 重跑注音，重新生成 script_annotated.txt
python3 scripts/annotate-polyphones.py --project-dir <项目>
# 3. 核对 config/polyphone_report.json 中新增条目
# 4. 重生成受影响行的音频
```

### 兜底：直接改注音文件（语境专属、无法字典化时）

直接编辑 `<项目>/config/script_annotated.txt` 对应行，格式同 §1。
注意：下一次重跑注音脚本会覆盖手改——这类规则最终仍应收进 WORD_RULES。

## 5. 禁止

- **不要**给非多音字加注音（无效且干扰可读性）
- **不要**用小写、带声调符号（`fóu`）、或无声调数字（`FOU`）的形式
- **不要**写旧版混排（`我XIANG4`）——已废弃，一律用 `<字|读音>`
- **不要**改动对比脚本的分级阈值/容错口径来「消掉」错音——修注音或修理解，不修尺子
